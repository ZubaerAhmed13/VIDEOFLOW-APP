# VideoFlow Android — Step 2 Test Report

## Status

PARTIAL

This repository report describes the certification gates. The GitHub Actions artifact `VideoFlow-Android-Step2-Build-Certification` records exact JVM test counts, commit/run identity, lint/build results, APKs, source ZIP and SHA-256 values for the exact tested commit. The emulator artifact records the exact API-35 instrumentation output/count.

## Automated gates

- Prohibited source-pattern audit: required.
- Room v2 schema + explicit MIGRATION_1_2 presence: required.
- Clean Gradle build: required.
- Step 1 regression + Step 2 JVM tests: required with zero failures.
- Android lint: required.
- Android instrumentation test compilation: required.
- Debug APK + instrumentation APK assembly: required.
- Test-signed release APK assembly: required.
- API 35 emulator install + instrumentation: required.
- Runtime/artifact SHA-256 verification: required.

## Coverage

The test suite covers Step 1 source identity/relink/persistence plus Step 2 migration, rational FPS/timebase, trim/split at multiple speeds, fade clamping, duplicate/source identity, track compatibility and audio policy, snapping, multi-hour structure, audio gain/fades, keyframe HOLD/LINEAR/local move/split, PreviewPlan proxy selection, RenderPlan determinism, validation and undo/redo invalidation. Instrumentation includes migration from a real v1 database carrying a multi-gigabyte media-size reference.

Instrumentation: generated by the emulator job as `STEP_2_INSTRUMENTATION_COUNTS.txt` from `am instrument` output.

No Step 2 blocker may be declared PASS merely from this template; the exact CI artifacts/run conclusion are authoritative.

## Physical device

Physical editor acceptance: NOT VERIFIED in hosted CI.

The Step 2 master acceptance scenario requires a physical Android device with real video, image and audio, plus the edit/proxy/reopen workflow and preferably the previously validated multi-GB source. This is intentionally not reported as PASS without device evidence.
